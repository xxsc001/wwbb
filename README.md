# Band Studio · 条带图像工作台

参考蓝白色条带编辑界面的双图同步纯静态网站。无需安装依赖、后端或 API Key。

## 使用

直接打开 `index.html`，或使用任意静态服务器。分别点击「导入左图」「导入右图」，或将 PNG/JPG/WebP 拖入对应区域。在左图拖动，右图同步应用对应笔触。支持揉边、平滑、加深、减淡、画笔半径与力度调整、双图撤销/重做、双图原图对比和恢复原图。适配手机和桌面。

用「联动缩放」将两张图同时放大至 500%。选择「移动视野」后在左图拖动，右图跟随同一相对位置；也可以在左图用滚轮围绕光标缩放。选择「笔刷编辑」继续处理图片。

先导入一张图，打开对应的「裁切左图」或「裁切右图」，设置截图宽高，拖动取景框并按需旋转或调倍率。选择「保存为模板」后，后续导入会尝试识别条带并按模板宽高裁切。模板保存在当前浏览器；定位不明确时用模板保存的位置，仍可从完整原图手动微调。

用裁切弹窗中的「导出这张截图」直接下载单张截图，支持 300 DPI、PNG/JPEG/TIFF、可选像素尺寸及 JPEG 画质。默认保留截图宽高。也可选择「应用裁切」把结果放回工作台继续编辑。

「一键导出两张图」下载一个 ZIP，里面有独立的左右图文件，均写入 300 DPI。可选无损 PNG、无损 TIFF 或可调画质的 JPEG。可保留画布尺寸，或设置输出长边，两张图各自保持宽高比。放大输出像素会进行插值。导出使用完整画布，界面缩放与平移只影响预览。

位置和笔刷范围按左右图片宽高比例映射；半径滑块以左图像素为准。当图片宽高比不同时，右图笔刷会按对应轴比例变为椭圆。两图使用相同力度，但图像内容不同，处理结果也会不同。工具不会自动识别或对齐条带；需要对应同一实验区域时，请先确保两张图片构图一致。右图为只读结果预览。

导入新图会清空两图撤销历史，另一张图保留当前编辑结果；原图对比和恢复原图仍使用各自最初导入的图像。

默认展示程序绘制的模拟条带，不是实验数据。对真实科研图像的局部修改可能影响数据解释；请保留原始数据，并按适用规范披露图像处理。此工具不提供定量分析。

图片只在当前浏览器内存处理，不上传服务器，刷新页面会丢失编辑。单文件限制 30 MB，长边超过 2400 px 会等比缩小，透明区域导入后合成为白色背景。历史记录按图像大小保留最近 2–20 步。

## 上传 GitHub 并开启网站

1. 新建或打开目标 GitHub 仓库。
2. 将本目录中的 `index.html`、`style.css`、`app.js`、`export.js`、`crop.js`、`.nojekyll` 和本说明上传到仓库根目录。
3. 仓库 Settings → Pages，选择 Deploy from a branch。
4. 选择 main 分支和 / (root)，保存。
5. 等待 GitHub Pages 部署完成，在 Pages 页面打开生成的网址。

所有资源都使用相对路径，兼容仓库子路径部署。也可部署到其他静态托管平台。

## 文件

- `index.html`：页面和控件。
- `style.css`：响应式布局与配色。
- `app.js`：Canvas 笔刷、图像导入、历史记录和联动视野。
- `export.js`：图像格式编码、DPI 元数据和 ZIP 打包，无第三方依赖。
- `crop.js`：模板管理、条带定位、取景微调及单张截图导出。
